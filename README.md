# Vasilije Brkić – MH 34/2024

Eclipse Java 21 projekat za vežbe iz objektno orijentisanog programiranja.

## Dopuna primera za vežbanje

Paketi `src/domaci`, `src/geometry` i `src/vezbe2` dodati su kao **referentni primeri za učenje** iz javnog repozitorijuma [MihailoDakicMH22g2024](https://github.com/daakiic/MihailoDakicMH22g2024) (izvorni commit `4c531a56cb453d04e44bfb840693572a0501f787`). Autor originalnih primera je Mihailo Dakić; ovi fajlovi nisu predstavljeni kao samostalno izrađen rad.

Postojeći `src/vezbe/Main.java` i Eclipse konfiguracija u ovom projektu nisu menjani. Izvorni `.class` fajlovi nisu preneti jer Eclipse može da ih ponovo kompajlira.

### Pokretanje

Otvoriti folder `VasilijeBrkicMH34g2024` kao postojeći Java projekat u Eclipse-u (Java 21). Pokretati klase sa `main` metodom, kao što su `geometry.Testing`, `domaci.AutoTest`, `domaci.PetZadataka` i `vezbe2.ExplorersGame`.
